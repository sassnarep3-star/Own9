What blocks a decision, and the number that clears it.

Nine gates, the requirement lines each one holds, the measurement that would show it cleared, and how much of it is a decision rather than a purchase.

How to read this

A gate is only useful if it names the number that would clear it. Gates are ordered by the count of requirement lines they hold, so the top row is the one to work on first — unless it is the one that cannot be worked on at all, which is precisely the point of publishing the cost class beside it.

Research, not betting advice. No verified edge, calibrated model or guaranteed return is claimed. A blank empirical value is unavailable and unverified, never zero.
