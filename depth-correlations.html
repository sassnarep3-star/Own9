RESEARCH DESK / DEPTH & CORRELATIONAs of 14 Nov 2026 · UTC

How deep the replacement runs.
What the data can actually support.

Two of the eight requirements share a page because they share a failure mode: a fact that looks complete without a denominator. A replacement is not "a backup started", it is a distance travelled down a chart that may not exist; a correlation is not a number, it is a number with an n attached.

One case on this page shows why the count is the wrong unit

Kansas City has no out-of-lineup starting defensive tackle: Chris Jones plays. But the chart's second tackle is Out, so the third string starts. A vacancy count reports nothing interesting here and a depth measure reports the whole thing — which is what the requirement asked for.

Limits on the depth measure

Limits on the depth measure
LimitStatementEvidence / scope
Chart order is not a game-day recordA club chart lists who is next in the pecking order on the day it was published. Lines, packages and inactive lists are decided later, and this project has no certified per-game depth source.Published limitationOwn9 repository (primary project record) ↗
Club charts self-declare unofficialThe Chiefs and Lions pages retrieved 2026-11-14 carry the wording "Unofficial Depth Chart" in their own headings. A source that labels itself unofficial is used for ordering and cited, never upgraded.Published limitationOwn9 repository (primary project record) ↗
Distance is not damageTwo strings deep is a count, not a value. No performance drop per string is estimated here, because no verified starter-versus-replacement production sample exists in this repository.Published limitationOwn9 repository (primary project record) ↗
No per-play denominatorThe league publishes eleven statistics categories and none of them is snaps or participation, so a replacement who takes over half the reps and one who takes five look identical to the data available.Published limitationOwn9 repository (primary project record) ↗
Conditional is not absentA Questionable starter generates no vacancy row by default. Turning a probability the report does not publish into a certain absence would inflate every count.Published limitationOwn9 repository (primary project record) ↗

The correlation gate, as rules

The correlation gate, as rules
RuleStatementEvidence / scope
SourcesEvery observation names a registered official source. One unregistered leg voids the whole pair, not just that row.Project gate · method supportSciPy project ↗
AlignmentBoth legs must come from the same game, and each game enters a pair-set once. Cross-game row mixing is rejected.Project gate · method supportSciPy project ↗
Denominatorn is counted from the complete pairs actually used, never typed. n is printed with every value, including values that are refused.Project gate · method supportSciPy project ↗
Missing legsAn observation missing either leg is dropped and counted. It is not imputed, and it does not shrink the denominator silently.Project gate · method supportSciPy project ↗
Constant legUndefined, reported as undefined. Never replaced by 0.0.Project gate · method supportSciPy project ↗
ActionA value may change a joint price only when the interval clears both the MIN_N (30) and the deadband (0.1), predeclared before measurement.Project gate · method supportSciPy project ↗

Interpretation, stated plainly: at eleven to fifteen games no interval here is narrow enough to clear the predeclared floor, so no joint price is produced and no independence is assumed either. The pair that would most tempt a reader — prior record gap against final margin — has a point estimate of -0.661377 at n=11, an interval of [-0.902995, -0.10195], and a verdict of insufficient_evidence. The interval clears the deadband; the sample does not clear the floor. That asymmetry is the gate working. See Correlations for the predeclared pair definitions this register measures against.
