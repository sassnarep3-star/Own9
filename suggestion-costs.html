Two constraints shape every option here. Luck cannot be removed, only bounded, so any path that promises a guaranteed edge should be rejected on sight. And no official source publishes NFL wagering lines, so paths A and D differ from path B mainly in whether the price history is grown or bought. Recorded decisions should be mirrored into COORDINATION.md so the next session can see them.

Research, not betting advice. No verified edge or guaranteed return. Blank empirical values are unavailable and unverified, never zero.
