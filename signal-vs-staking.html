RESEARCH DESK / SIGNAL VS STAKINGAs of 14 Nov 2026 · UTC

Two columns.\nTwo ranks. Never mixed.

A leaderboard that ranks what a strategy knew separately from how it was staked, so a lucky staking run cannot carry a weak signal and a strong signal is not buried by a conservative stake. Includes the demotion gate that sends a live strategy back to paper.

The split

Signal is what the model knew before kickoff: which markets it took, what it declined, and how its probabilities scored. Staking is what was risked afterwards: units, return, drawdown. They are different questions with different luck, so they get different columns and different ranks.

Read this page together with the Leaderboard and Validation pages, which publish the same two ideas as policy tables written by earlier sessions. Both are live on this site; which one becomes canonical is an owner decision, recorded as F57 rather than decided here.

The worked example above is deliberately built so that the strongest signal is not the biggest return and the biggest return is not the strongest signal. That is the normal case, and the two ranks exist so neither can be mistaken for the other.

Demotion gate

A live strategy is sent back to paper when the live period stops supporting it. Every threshold is fixed before the period starts. A window with a missing measurement does not pass the gate: an unmeasured signal score is treated as a breach, because a strategy that cannot be measured cannot be trusted with money.
