The file in data/raw/ is a real dataset, and this release is the first to measure it instead of describing it as absent. It is also too incomplete and too undocumented to support a claim of any kind, so it is quarantined and published on Flagged for Review as F22. The decision the owner has to make is whether to licence a current source or build a prospective capture archive from now on; S04 and S05 set out both paths.
